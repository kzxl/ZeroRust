# `zero-zconn` ⚡🖥️🌐

> Sovereign ultra-low-latency remote desktop host daemon, client engine, and C-FFI bindings for ZConn in ZeroRust.

## Features
- **Integrated Host Daemon**: High-frequency capture, tile diffing, encoding, UDP multiplexing, and synthetic input injection.
- **Client Presentation Engine**: Jitter buffer, tile reassembly, delta decompression, and BGRA render surface.
- **C-FFI & P/Invoke Ready**: Directly binds to ZeroPlatform (.NET C# WinUI / WPF) without third-party wrapper libraries.
- **Zero-Allocation Video Pipeline**: Operates completely in pre-allocated memory pools.
